# 家长验收检查清单

打开方式：
- 电脑浏览器：http://localhost:3000
- 手机（和电脑连同一个 WiFi）：http://192.168.1.157:3000

建议按顺序逐条检查，符合预期就打勾。

---

## 一、首页「今天」

- [ ] **同一件事只出现一次**：今天的日程列表里，同一个孩子的同一个安排不会重复展示两遍。
- [ ] **「近期安排」标题**：今天之后的安排区块，标题应显示为「近期安排」，不应是英文或别的旧叫法。
- [ ] **紧急度标签统一**：所有紧急/重要标签（如「今天」「即将到期」等）用词全站一致，不会这里叫一个名字、那里叫另一个名字。
- [ ] **每日简报读得懂**：顶部的今日概览是通顺的中文，没有夹杂英文短语或程序味的文案。

## 二、日程页

- [ ] **新增日程能保存**：新增一个日程（随便填个明天的补习），保存后**刷新页面**，这条日程还在。
- [ ] **日历时间是中文**：日历里的星期和时间显示为中文格式（如「周一 08:00」），不是英文（如「Mon 8:00 AM」）。
- [ ] **删除/编辑正常**：删掉刚才的测试日程，列表和日历里都消失了。

## 三、记录页

- [ ] **录入成绩后趋势图正常**：给任一孩子录一条成绩，趋势图能正常画出来，不报错、不空白。
- [ ] **零数据空状态**：切到一个还没有任何记录的孩子/科目，看到的是友好的中文提示（告诉你还没有记录、该怎么添加），不是报错或空白一片。
- [ ] **家教反馈展示**：记录页里的家教反馈区块文案通顺，能看懂每条反馈是谁、什么时候、说了什么。

## 四、设置页

- [ ] **没有技术黑话**：整个设置页看不到 Supabase、Vercel、「演示模式」这类字样，普通家长看得懂每一项是干什么的。
- [ ] **下载按钮只有一个**：数据导出/备份处只有一个下载按钮，不再是两个功能重复的按钮。
- [ ] **导出报告标题是中文**：导出中心里的报告名称、说明都是中文。

## 五、家教流程（完整走一遍）

- [ ] **生成专属链接**：在设置页给家教生成一个专属反馈链接，能一键复制。
- [ ] **无痕窗口打开**：新开一个无痕/隐私浏览窗口，粘贴链接打开，能看到家教反馈填写页（不需要登录家长账号）。
- [ ] **提交反馈**：以家教身份填写并提交一条反馈，提示提交成功。
- [ ] **家长端能看到**：回到家长端记录页，刚才提交的那条反馈已经出现。

## 六、手机上检查（用 http://192.168.1.157:3000）

- [ ] **底部导航正常**：底部导航栏完整显示、不遮挡内容，点击切换页面正常。
- [ ] **顶栏不重复**：页面顶部标题下方的副文案只出现一次，没有重复显示两遍的情况。
- [ ] **按钮好点**：常用按钮（新增、保存、复制链接等）用手指容易点中，不会误触到旁边的按钮。
- [ ] **没有横向滚动**：任何页面左右滑动时，页面不会整体横向移动（没有横向滚动条）。
- [ ] **样式没丢**：页面有正常的颜色、卡片、圆角等样式，不是光秃秃的纯文字（如果出现纯文字裸奔，说明样式文件没加载出来）。

---

发现问题时，请记下：在哪个页面、做了什么操作、看到了什么、期望看到什么。
