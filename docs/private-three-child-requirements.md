# 伯仲叔家庭教育管理系统 v1 需求对齐

> 私有定制版文档。不要提交到公开 GitHub main 分支。

## 产品定位

伯仲叔家庭教育管理系统 v1 是面向当前家庭的私有教育运营中枢。它不是通用 SaaS 的公开演示页，而是家长明天就能打开使用的三孩教育管理工作台。

核心目标：

- 每天快速知道三个孩子今天和本周要处理什么。
- 分别管理伯杨、仲杨、叔杨的阶段目标、学习记录、课程安排和资源。
- 降低家长在学校、补习、活动、考试、资料和长期规划之间切换的成本。
- 保留未来抽象成通用商业版的数据结构。

## 明日交付范围

### 产品形式

先交付“框架可用版”，不依赖完整真实日程。

- 今晚完成系统框架、孩子档案结构、日历结构、目标结构、资源结构和家长补充入口。
- 明天和家长见面时，在系统内补学校、课表、考试、活动、目标和关注点。
- 现场补充的数据先保存在本机浏览器，后续再迁移到 Supabase。
- 分享形式优先支持复制周报框架、截图、私有链接或本地演示。
- 家长补充数据支持导出 JSON 备份，后续可再导入到本机版本或迁移到云端。
- 本机日程编辑器支持新增/删除事项，新增事项会进入总览、统一日历和当前页面 ICS 导出。
- 家长版周报支持复制摘要、打印和另存 PDF，作为明天现场交付材料。

### 编辑与分享策略

1. 明天现场：使用本地 demo 或私有预览链接，由家长在“现场补充工作台”编辑，系统自动保存到浏览器。
2. 当天交付：导出 JSON 备份，复制周报框架，必要时下载 ICS 导入 Apple 日历。
3. 做好后分享：优先使用 private Vercel 项目或带访问码的私有链接，不把定制数据推到公开 GitHub。
4. 伯仲叔长期使用：不要求家长登录，通过私有访问码/私有链接进入，服务端把数据写入 Supabase。
5. 大众商业版长期使用：再接 Supabase Auth 和 Postgres，家庭成员登录后实时编辑，日历订阅源从数据库动态生成。

### 私有访问保护

- 本地开发默认不启用访问码。
- 私有部署时设置 `PRIVATE_PARENT_ACCESS_CODE`，页面会先进入 `/access`。
- iOS 日历订阅使用数据库里的 `family_settings.calendar_token`，可通过轮换该字段撤销旧订阅链接。
- 伯仲叔特制版不强制登录，访问码就是正式私有入口。
- 大众商业版再使用 Supabase Auth、家庭成员角色和更完整权限。

### P0 必须完成

- 家庭总览：今日重点、本周安排、三孩状态摘要、家长待办。
- 家长版周报：面向家长的一页式只读摘要。
- 三孩管理矩阵：伯杨、仲杨、叔杨横向对比。
- 家长现场补充工作台：按孩子补学校、固定课表、重要日期、阶段目标和关注点。
- 日程编辑器：现场新增学校、补习、活动、考试和家庭事项。
- 孩子档案：阶段、学校信息、课程体系、关注重点、近期记录。
- 统一日历：学校、补习、活动、考试、家庭事项统一展示。
- iOS 日历同步：提供 Apple Calendar 兼容 ICS 下载和私有部署后的 webcal 订阅入口。
- 成长追踪：学习记录、目标进度、月度观察入口。
- 学习资料库：保存试卷、讲义、错题照片、阅读材料、网盘链接和资料备注。
- 孩子自我评价：记录孩子自己的心情、投入、掌握程度、反思和下一步。
- 家教课后反馈：记录每次家教课的重点、表现、课后任务和下次方向。
- 教育路线图：每个孩子的阶段目标和里程碑。
- 资源中心：笔记、资料、练习包、家庭模板。
- 移动端可用。
- 定制数据只保留在私有分支或私有部署，不进入公开 GitHub。

### 已接入长期版能力

- Supabase 持久化，伯仲叔版通过私有服务端 API 写入，不要求家长登录。
- 家长现场补充日程实时进入 iOS 订阅源。
- 学习资料文件迁移到 Supabase Storage，支持多设备长期访问。
- 孩子档案、日程、学习记录、路线图、学习资料、自评和家教反馈支持数据库增删改。
- JSON 导出和命令行恢复演练。
- iOS 日历 token 可在数据库轮换。

### P1 可随后增强

- 大众商业版登录和家庭权限。
- 月报导出。
- AI 学习建议。
- Vercel 私有部署。

## 需要继续补充的信息

为了把明天版本做得更像成品，需要继续确认：

1. 三个孩子的真实年龄或出生年份。
2. 学校名称是否要展示，还是统一匿名为“主学校”。
3. 每个孩子固定周课表：补习、兴趣班、运动、接送时间。
4. 最近 30-90 天的重要考试、活动、比赛、面试或报名截止日期。
5. 家长最关心的提醒维度：作业、成绩、习惯、情绪、升学、时间管理。
6. 明天演示方式：本地运行、私有 Vercel 链接，还是录屏/截图。

## 隐私规则

- 公开 GitHub 只保留通用商业版。
- 伯仲叔定制版只在 `main` 私有本地分支推进。
- 真实姓名、学校、课程机构、联系方式、地址、考试编号等敏感信息不进入公开仓库。
- 如果未来需要部署，优先使用 private repo 或 Vercel 私有项目。
