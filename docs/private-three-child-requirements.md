# 伯仲叔家庭教育管理系统 v1 需求对齐

> 私有定制版文档。不要提交到公开 GitHub main 分支。

## 产品定位

伯仲叔家庭教育管理系统 v1 是面向当前家庭的私有教育运营中枢。它不是通用 SaaS 的公开演示页，而是家长明天就能打开使用的三孩教育管理工作台。

核心目标：

- 每天快速知道三个孩子今天和本周要处理什么。
- 分别管理伯杨、仲杨、叔杨的阶段目标、学习记录、课程安排和资源。
- 降低家长在学校、补习、活动、考试、资料和长期规划之间切换的成本。
- 保留未来抽象成通用商业版的数据结构。

## 明日交付范围

### P0 必须完成

- 家庭总览：今日重点、本周安排、三孩状态摘要、家长待办。
- 三孩管理矩阵：伯杨、仲杨、叔杨横向对比。
- 孩子档案：阶段、学校信息、课程体系、关注重点、近期记录。
- 统一日历：学校、补习、活动、考试、家庭事项统一展示。
- 成长追踪：学习记录、目标进度、月度观察入口。
- 教育路线图：每个孩子的阶段目标和里程碑。
- 资源中心：笔记、资料、练习包、家庭模板。
- 移动端可用。
- 定制数据只保留在私有分支或私有部署，不进入公开 GitHub。

### P1 可随后增强

- Supabase 持久化。
- 登录和家庭权限。
- 文件上传。
- 月报导出。
- AI 学习建议。
- Vercel 私有部署。

## 需要继续补充的信息

为了把明天版本做得更像成品，需要继续确认：

1. 三个孩子的真实年龄或出生年份。
2. 学校名称是否要展示，还是统一匿名为“主学校”。
3. 每个孩子固定周课表：补习、兴趣班、运动、接送时间。
4. 最近 30-90 天的重要考试、活动、比赛、面试或报名截止日期。
5. 家长最关心的提醒维度：作业、成绩、习惯、情绪、升学、时间管理。
6. 明天演示方式：本地运行、私有 Vercel 链接，还是录屏/截图。

## 隐私规则

- 公开 GitHub 只保留通用商业版。
- 伯仲叔定制版只在 `codex/private-three-child-pilot` 私有本地分支推进。
- 真实姓名、学校、课程机构、联系方式、地址、考试编号等敏感信息不进入公开仓库。
- 如果未来需要部署，优先使用 private repo 或 Vercel 私有项目。
