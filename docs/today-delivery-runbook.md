# 今日现场交付 Runbook

> 伯仲叔特制版现场使用清单。目标是稳，不临场扩功能。

## 现场开场

1. 打开伯仲叔教育管理 PWA。
2. 简单说明：这是私有家庭教育管理应用，不是公开网站。
3. 说明当前不要求家长注册登录，后续通过私有链接和访问码使用。

## 演示顺序

1. 家庭总览：先看本周事项、教育目标、孩子档案。
2. 家长版周报：展示一页式摘要，可复制、打印、存 PDF。
3. 家长现场补充工作台：按伯杨、仲杨、叔杨补学校、课表、重要日期、目标、关注点。
4. 日程编辑器：现场新增一个真实日程，确认它进入总览和统一日历。
5. iOS 日历同步：下载当前页面 ICS，说明私有部署后可订阅自动同步。
6. 手机桌面私有 App：说明家长可在 iPhone Safari 中添加到主屏幕。

## 必问信息

每个孩子只问这些，避免发散：

- 学校 / 班级 / 课程体系是否需要展示。
- 固定周课表：补习、兴趣班、运动、接送。
- 未来 30-90 天重要日期：考试、报名、面试、比赛、假期。
- 本月最重要的 1 个目标。
- 家长最担心的 1 个问题。

## 现场交付物

- 周报 PDF 或截图。
- 当前页面 ICS 文件。
- JSON 资料备份。
- 后续私有 PWA 链接方案说明。

## 不在现场做

- 不做大众商业版讨论。
- 不现场接复杂登录权限。
- 不承诺原生 App。
- 不把伯仲叔数据推公开 GitHub。
